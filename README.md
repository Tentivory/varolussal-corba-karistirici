# VAROLUŞSAL ÇORBA KARIŞTIRICI

## Dünyanın En Ciddi, En Absürt ve En Gereksiz Projesi

Bu proje, çorba karıştırma eyleminin derin varoluşsal boyutlarını keşfetmek için tasarlanmıştır. Her bir karıştırma hareketi, evrenin anlamsızlığına bir başkaldırıdır. Veya belki de sadece çorba soğumasın diye.

### Nasıl Çalışır?

```bash
python corba_karistir.py
```

Program sonsuz döngüde çorbanızı karıştırır, arada derin felsefi sorular sorar ve sizden cevap beklemez. Çünkü cevap yoktur. Veya vardır ama çorba soğudu.

### Özellikler

- Sonsuz karıştırma
- Rastgele varoluşsal krizler
- Çorba sıcaklığını asla ölçmez
- Anlam arama garantisi (bulunamaz)
